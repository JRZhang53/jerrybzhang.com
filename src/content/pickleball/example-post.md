Copy this file to start a new post. The filename becomes the URL, so `league-night.md`
would live at `/pickleball/league-night/`.

Write normally in Markdown. To add a photo, put it in `public/pickleball/` and write:

![Doubles finals](/pickleball/doubles-finals.jpg)

To embed a YouTube clip, paste its embed code:

<iframe src="https://www.youtube.com/embed/VIDEO_ID" title="Rally clip" allowfullscreen></iframe>
